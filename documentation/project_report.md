# AI Resume Analyzer & Interview Preparation System

## 1. Project Overview

This project demonstrates the use of Prompt Engineering to design
a structured AI workflow for resume analysis and interview preparation.

## 2. Problem Statement

HR recruiters may spend significant time manually analyzing resumes
according to job requirements, identifying relevant skills and
preparing suitable interview questions.

## 3. Objective

To design a structured AI workflow that analyzes candidate
information, compares it with job requirements, identifies skill
gaps, generates interview questions and evaluates the generated
questions.

## 4. Workflow

Resume + Job Description
        ↓
Information Extraction
        ↓
Skill Gap Analysis
        ↓
Interview Question Generation
        ↓
Question Evaluation
        ↓
Final Interview Report

## 5. Prompt Engineering Techniques

- Role Prompting
- Contextual Prompting
- Prompt Decomposition
- Prompt Chaining
- Structured Outputs
- Grounding
- Hallucination Control
- Prompt Evaluation
- Prompt Refinement
- Prompt Optimization

## 6. Final Output

The system produces:

- Candidate Profile
- Job Requirements
- Matching Skills
- Skills Not Mentioned in Resume
- Skill-Gap Based Questions
- Technical Questions
- Project-Based Questions
- Problem-Solving Questions
- Question Quality Evaluation
- Final Interview Preparation Summary

## 7. Limitations

The system depends on the information provided in the resume and
job description.

A skill not mentioned in a resume does not prove that the candidate
does not possess that skill.

AI-generated questions should be reviewed before practical use.

## 8. Future Enhancements
