# Prompt Evaluation

## Evaluation Criteria

The generated outputs are evaluated using the following criteria:

1. Accuracy
2. Relevance
3. Completeness
4. Clarity
5. Structured output compliance
6. Technical correctness
7. Duplication
8. Skill coverage
9. Skill-gap coverage
10. Suitability for a fresher

## Evaluation Process

Prompt
↓
Generate Output
↓
Evaluate Output
↓
Identify Problems
↓
Refine Prompt
↓
Generate Again
↓
Compare Results

## Important Validation Rule

The system must not assume that a candidate lacks a skill simply
because the skill is not mentioned in the resume.

Example:

React.js → Not mentioned in resume

NOT:

Candidate does not know React.js.
